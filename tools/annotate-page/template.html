RSI 论文标注台

给出论文链接和 PDF，Claude 按仓库的标注规则填好每个字段，把拿不准的地方列成选项和建议。你逐项决定后，生成一个带完整标注的 Issue；仓库的流程自动建分支和 PR，你在 Issue 下评论 /confirm 完成收录。

1

论文

链接用于查重和记录，正文来自 PDF 或粘贴的文本
把 PDF 拖到这里，或点左边选择文件。文件只在你的浏览器里读取。
没有 PDF？改为粘贴正文或摘要
2

核对标注

先决定不确定的地方，再过一遍全部字段
3

提交到 GitHub

这里只是创建 Issue；确认收录要在 Issue 下评论 /confirm
在 GitHub 新建 Issue

  1. 在打开的 GitHub 页面点 Submit new issue。
  2. 一两分钟后，流程自动创建分支 paper/issue-N 和 PR，并把标注表格贴在 Issue 下面。
  3. 你对照原文核对后，在 Issue 下评论 /confirm，论文写入清单，PR 和 Issue 自动关闭。
